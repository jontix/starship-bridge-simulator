# Starship Bridge Simulator

An early prototype of a cooperative, browser-based, 3D starship bridge simulator.

## Stack

- TypeScript workspace monorepo
- React and Babylon.js browser client
- Node.js and Colyseus authoritative game server
- Shared simulation and command types

## Getting started

```bash
npm install
npm run dev
```

Open the Vite development URL (typically http://localhost:5173) in two browser tabs and choose Helm and Main Screen.

This is a prototype scaffold, not a finished or verified build.
